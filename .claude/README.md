# Skills y material de diseño del proyecto

Instalado a mano (sin `npx`) clonando cada repo y copiando los archivos.

## skills/

- **impeccable** — `pbakaus/impeccable` v4.3.1, Apache 2.0.
  Diseño de frontend: `audit`, `critique`, `polish`, `document`, `init`, entre otros.
  `document` genera un DESIGN.md a partir del código que ya existe.
  Copiado de `plugin/skills/impeccable/`. Los agentes y hooks del plugin no están instalados.
  El launcher `scripts/impeccable` descarga un binario la primera vez que corre.

- **slides** — `nghiahsgs/skills-slides`.
  Presentaciones HTML autocontenidas, sin dependencias. Sirve para carruseles de Instagram.

## design/

Material de referencia, no son skills: no se cargan solas, se leen cuando hacen falta.

- **awesome-design-md** — `VoltAgent/awesome-design-md`. 75 archivos DESIGN.md de sistemas de diseño de marcas conocidas.
- **google-design-md** — `google-labs-code/design.md`, Apache 2.0. Especificación del formato DESIGN.md de Google (Stitch), su filosofía y ejemplos.
