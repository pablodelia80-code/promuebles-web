How It Works

Token-Based Design System

  • →Describe your vibe: "dark techy startup energy"
  • →Search engine matches aesthetics, palettes, fonts, effects

Search Tokens

Find your style in seconds

terminal 
# Find aesthetics by vibe
$ python search.py "dark futuristic" --domain aesthetic

# Get the full compatible design system
$ python search.py --compatible startup-pitch

# Fetch a specific token
$ python search.py --get palette midnight-aurora

Quality Gate

10-Point Anti-Slop Checklist

  • ✓ No generic display fonts
  • ✓ No purple-on-white gradient
  • ✓ Shadow hierarchy (sm/md/lg)
  • ✓ All colors via CSS variables
  • ✓ All font sizes use clamp()
  • ✓ Signature visual effect
  • ✓ Background has depth
  • ✓ 3+ distinct text sizes
  • ✓ WCAG AA 4.5:1 contrast
  • ✓ prefers-reduced-motion
